# AutoKit — Скрипты автоматизации на Python

Коллекция практичных скриптов: Wake-on-LAN по расписанию, управление устройствами через UniFi API, Telegram-автоотправитель.

## Скрипты

| Скрипт | Назначение |
|--------|-----------|
| `python_wol_8_00.py` | Wake-on-LAN — включение машин по расписанию |
| `unifi_api_block_unblock.py` | Блокировка/разблокировка устройств через UniFi API |
| `telegram-autosend` | Автоматическая отправка сообщений в Telegram |

## Использование

```bash
python3 python_wol_8_00.py
python3 unifi_api_block_unblock.py --mac AA:BB:CC:DD:EE:FF --action block
```
